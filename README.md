# Ilmzen

Software company site. Light mode only.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Theme

Defined in `app/globals.css`. The page background is white and the typeface is Inter.

| Token | Hex | Use |
| --- | --- | --- |
| Charcoal | `#0B0B0B` | Text and buttons |
| Electric blue | `#0066FF` | Reserved. Not applied to buttons or text yet |
| Cool gray | `#E5E7EB` | Borders and dividers |
| White | `#FFFFFF` | Page background |
